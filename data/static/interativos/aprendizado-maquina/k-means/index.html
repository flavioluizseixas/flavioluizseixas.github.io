Como o k-means agrupa pontos

O k-means separa dados em k grupos repetindo duas ideias simples: cada ponto escolhe o centro mais próximo, e cada centro vai para o meio dos seus pontos. Avance passo a passo e observe.

Clique para adicionar pontos · arraste os ✕ para mover centroides

O algoritmo

  1. 1Sortear k centroides iniciais
  2. 2Cada ponto vai para o centroide mais próximo
  3. 3Cada centroide vai para a média dos seus pontos
  4. 4Repetir 2 e 3 até ninguém mudar de grupo
Iteração 0 Erro total
—

Soma das distâncias ao quadrado de cada ponto até seu centroide. Quanto menor, mais “apertados” estão os grupos. No k-means ele nunca aumenta.
